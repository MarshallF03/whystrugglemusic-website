# Why Struggle Music website

Website for Why Struggle Music (WSM), run by Bradley McKnight. Published by GitHub Pages at www.whystrugglemusic.com.

## How it works

- Anything pushed to the `main` branch goes live automatically, usually within a minute or two.
- The `CNAME` file tells GitHub Pages which domain to use. Don't delete or rename it.
- The domain is registered with Fasthosts. DNS points `whystrugglemusic.com` and `www` at GitHub Pages. Email and the planned `shop.` subdomain are separate DNS records at Fasthosts and are not affected by this repo.

## Planned pages

Home, About, Services, Why Struggle Records (label and roster), Music business resources hub, Shop (external, at shop.whystrugglemusic.com), Improving accessibility in music, Contact. Terms and conditions and licence agreements to follow.

Right now the site is a single "coming soon" page.

## Writing style

All text on the site uses British English spelling (colour, organise, licence as a noun, programme, catalogue, and so on). Please check spelling before pushing.
